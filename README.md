# The Boss · downloads

Your coding agents (Claude Code, Codex, Gemini CLI, Copilot CLI, Cursor, Pi, omp) as robots in a pixel-art office.

Get the latest version from the [releases page](https://github.com/flcarre/theboss-releases/releases/latest) or from
https://theboss-iota.vercel.app/#download:

| System | File |
|---|---|
| macOS 11+ (Apple Silicon and Intel) | `TheBoss-macOS.dmg` |
| Windows 10 and 11 | `TheBoss-Windows-setup.exe` |
| Linux x86_64 | `TheBoss-Linux.AppImage` or `TheBoss-Linux.deb` |

The builds are not signed yet. On macOS, right-click the app and choose Open the first time. On Windows, click
More info, then Run anyway if SmartScreen shows up.

This repository only holds the installers.
